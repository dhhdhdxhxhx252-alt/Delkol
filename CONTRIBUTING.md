# Руководство по содействию проекту Delkol 🚀

Привет! Мы очень рады, что вы хотите помочь в развитии проекта **Delkol**. Вклад каждого участника делает этот инструмент лучше.

Пожалуйста, ознакомьтесь с этим руководством перед тем, как создавать задачи (Issues) или отправлять изменения в код (Pull Requests).

---

## 1. Как правильно создавать Issues (Задачи)

Если вы нашли ошибку (баг) или у вас есть идея по улучшению проекта, пожалуйста, создайте [Issue](https://github.com/dhhdhdxhxhx252-alt/Delkol/issues).

### Для сообщений об ошибках (Bug Reports):
Перед созданием убедитесь, что такой ошибки еще нет в списке открытых задач. В описании укажите:
1. **Четкое название** проблемы (например: *"Ошибка авторизации при пустом токене"*).
2. **Шаги для воспроизведения** (шаг 1, шаг 2, шаг 3...).
3. **Ожидаемое поведение** (как должно работать) и **фактическое поведение** (что пошло не так).
4. **Окружение**: ваша операционная система, версия языка программирования (например, Python 3.10 / Node.js 18) и версия проекта.
5. По возможности, прикрепите скриншоты или логи ошибки.

### Для предложений (Feature Requests):
1. Опишите, какую проблему решит ваше предложение.
2. Опишите желаемый функционал и то, как вы видите его реализацию.
